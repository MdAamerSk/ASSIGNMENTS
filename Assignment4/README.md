# Bento Portfolio Dashboard

A simple and beautiful personal portfolio using the Bento Grid layout.

## ✨ Features
- **Dark Mode**: Premium black and gray theme.
- **Bento Grid**: Modern tile-based layout.
- **Socials & Tech**: Easy-to-edit icons for social media and skills.
- **Mobile Friendly**: Clean and responsive design.

## 🛠️ Files
- `index.html` - The structure.
- `style.css` - The design and layout.

## 🚀 How to Use
Just open `index.html` in any browser to view your portfolio!
