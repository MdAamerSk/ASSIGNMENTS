## 🎯 Project Overview

This is a complete responsive web design project showcasing a premium tea e-commerce platform. The website features a beautiful, modern design with smooth animations, interactive components, and a fully functional mobile-first approach.

**Built for:** Sheryians Cohort 3.0 Assignment  
**Date:** 2026

---

## ✨ Key Features

- **📱 Fully Responsive Design** - Seamlessly adapts from mobile to desktop
- **🎨 Modern UI/UX** - Clean, professional design with smooth transitions
- **🛍️ Product Showcase** - Interactive product cards with hover effects
- **🔍 Search & Filter** - Search functionality and tea filtering by vibe/category
- **⭐ Customer Reviews** - Dedicated review section with product ratings
- **📰 Tea Journal** - Blog-style section with tea articles and recipes
- **🏪 Cafe & Wholesale Section** - Information for business partners
- **📧 Newsletter Signup** - Footer email subscription
- **🎭 Smooth Animations** - Hover effects and transitions throughout

## 🎨 Design Highlights

### Color Palette
- **Primary Colors:** #fbf9eb (cream), #2a2857 (dark), #201c1a (charcoal)
- **Accent Colors:** Various pastels per product category
- **Background Colors:** Cream, white, and custom section backgrounds

### Typography
- **Headers:** Reckless, Midnight (for bold impact)
- **Body Text:** Figtree (modern, readable)
- **Decorative:** Midnight for badges and labels

### Interactive Elements
- Hover effects on cards and buttons
- Smooth transitions (0.2s - 0.3s)
- Scale animations on product images
- Color change on interactive elements
- Rotated badges for visual interest

---

## 💻 Responsive Breakpoints

The design uses `clamp()` for fluid typography and flexbox/grid for layout:
- **Mobile:** Default (< 600px)
- **Tablet:** 600px - 1024px (adjusted spacing)
- **Desktop:** 1024px+ (full layout)
