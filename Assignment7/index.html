Browser Rendering Pipeline

How a browser transforms raw HTML code into pixels on the screen.

Step 1

HTML Parsing

The browser processes raw bytes of HTML from the network and decodes them based on the specified character encoding.

Step 2

Tokenization

The parsed characters are converted into distinct tokens (StartTag, EndTag, Attribute, Character) based on HTML5 standard rules.

Step 3

DOM Tree

Tokens are linked into a tree structure of nested nodes, representing the document's logical object structure.

Step 4

CSSOM Tree

The browser parses external and embedded stylesheets to build a tree of cascading style rules for elements.

Step 5

Render Tree

The DOM and CSSOM are combined. Nodes that are styled to be visible are matched and structured into a rendering tree.

Step 6

Layout & Paint

The layout step computes geometric positions of nodes. The paint step translates nodes into actual pixels on the screen.
