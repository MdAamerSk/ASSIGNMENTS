# Pikachu Landing Page

A beginner-friendly HTML and CSS project that demonstrates the power of CSS positioning (`relative` and `absolute`).

## Features
- **Modern Design**: A clean, two-tone layout inspired by the Pokemon world.
- **Pure HTML/CSS**: No frameworks, no JavaScript, just core web technologies.
- **Positioning Mastery**: Demonstrates how to use `position: absolute` for overlapping elements like the Pikachu image and navigation icons.

## How to use
Simply open `index.html` in any modern web browser to view the project.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- Remix Icons
